## Features:
- **Add Task** – Create a new task via a form
- **View Tasks** – Dashboard displays all saved tasks in a table, with total/pending/completed counts
- **Edit Task** – Update a task's name, description, due date, or status
- **Delete Task** – Remove a task (with confirmation prompt)
- **Update Status** – One-click toggle to mark a task as Pending or Completed
- **Filter Tasks** – View all, only Pending, or only Completed tasks
